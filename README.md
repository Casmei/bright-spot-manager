# Bright Spot Manager

Olá, eu te mandei a logo e uma página para vc ter como inspiração para o layout, o que eu quero que vc faça é duas coisas. O sistema é basicamente para solicitação para troca de lâmpadas queimadas ou apagadas. O sistema tem que contas com dois fluxos:

O primeiro, público, é para que qualquer pessoa possa fornecer informações da solicitação, inicialmente um ponto de gelocalização, aí quando a pessoa abre a página, o navegador pergunta se pode coletar a localização dela e já plota sua localização no mapa, a pessoa confirma ou pode inserir em um input (ou pode inserir o endereço, a primeiro momento, quero um input de texto único, e não um separado para cada atributo do endereço)


O segundo, fechado (quero sem autenticação no momento, coloque um botão mostrando a visão interna de chamados da cemig). Essa página eu quero que ela plote um mapa com todos os pontos geográficos no mapa, para a empresa ter uma noção no mapa de quais postes precisam de manutenção, eu tmb quero uma dinamica de cores, verdes são chamados abertos recentemente, amarelos que possuem mais de dias, vermelhos que possuem mais de 4 dias. Eu quero o mapa, mas eu tmb quero ao lado do mapa, uma listagem dos chamados, aí quando eu clico no chamado, da foco no ponto do mapa (Eu mandei um layout parecido, pique airbnb)
